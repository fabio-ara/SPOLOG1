# lista08_ex01 - Alunos com notas de matemática e física

## Enunciado bruto

1) Crie uma estrutura de dados heterogênea, usando Linguagem C, para receber nome e as notas de matemática e física, para 5 alunos. No final devem ser exibidos os nomes dos alunos suas respectivas médias aritméticas. E por fim, deve ser exibido o percentual de alunos com médias acima de 6. Observe que o programa está estruturado, porém você precisa desenvolver as partes faltantes para atender ao objetivo.
