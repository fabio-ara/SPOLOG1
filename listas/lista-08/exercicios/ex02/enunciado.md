# lista08_ex02 - Carros em leilão com ofertas

## Enunciado bruto

2) Crie uma estrutura de dados heterogênea, usando Linguagem C, para receber marca, modelo, ano de fabricação e 3 valores de ofertas para 10 carros que participaram de um leilão, ou seja, além de seus dados básicos, cada carro recebeu valores de ofertas de 3 participantes. No final exiba todos os dados cadastrados, os respectivos valores médios de cada um e a maior oferta entre todas que foram oferecidas.
