# lista09_ex04 - Cadastro de funcionarios de TI

## Enunciado bruto

4) Crie uma estrutura de dados heterogênea, usando Linguagem C, para receber os dados de funcionários de uma empresa de TI, como nome, RG, idade, estado civil, telefone e salário. Adote os seguintes procedimentos:

- a. Crie um vetor de cadastro de 5 elementos e permita a entrada desses 5 cadastros;
- b. Encontre o cadastro e o exiba, para a pessoa com maior idade entre os cadastrados;
- c. Mostre os cadastros dos solteiros;
- d. Exiba o(s) cadastros da(s) pessoas com salários superiores a R$ 8000;
- e. Exiba todos os cadastros em ordem alfabética.
