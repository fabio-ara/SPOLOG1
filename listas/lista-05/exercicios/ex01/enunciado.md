# lista05_ex01 - Média e conceito do aluno

## Enunciado bruto

1) Fazer o algoritmo usando Linguagem C, que leia as duas notas de um aluno e calculem a média. No final exiba a média 
final e o conceito final desse estudante. O conceito segue a tabela abaixo:

| Média final (ponderada) | Conceito |
| --- | --- |
| 8.0 \|- 10.0 | A |
| 7.0 \|- 8.0 | B |
| 6.0 \|- 7.0 | C |
| 5.0 \|- 6.0 | D |
| < 5.0 | E |
