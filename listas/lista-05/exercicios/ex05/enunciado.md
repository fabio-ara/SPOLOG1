# lista05_ex05 - Lucro de mercadorias

## Enunciado bruto

5) Desenvolva um programa em linguagem C, usando a estrutura do/while(), para um comerciante que deseja fazer o 
levantamento diário do lucro das mercadorias que ele comercializa. Para isto, quer registrar cada mercadoria com o 
nome, preço de compra (preço de custo) e preço de venda das mesmas, em seguida calcule o percentual de lucro em 
cada mercadoria – veja o exemplo abaixo:
