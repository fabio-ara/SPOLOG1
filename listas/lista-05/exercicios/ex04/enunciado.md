# lista05_ex04 - Contagem por intervalos

## Enunciado bruto

4) Usando a estrutura while(), escreva um programa na Linguagem C que leia uma quantidade desconhecida de números 
e conte quantos deles estão nos seguintes intervalos: [0-25], [26-50], [51-75] e [76-100]. A entrada de dados deve 
terminar quando for lido um número negativo.
