# lista06_ex04 - Vetores A, B e C com validações

## Enunciado bruto

4) Crie uma matriz unidimensional A e uma B com 12 elementos cada (usando do/while()). A deve aceitar apenas valores que sejam divisíveis por 3 ou 7, enquanto B deve receber valores de A que não sejam múltiplos de 5 (as validações devem ser feitas pelo programa e não pelo usuário). Crie uma matriz C com os elementos de A e B. No final devem ser exibidas as três matrizes separadamente.
